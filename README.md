JetBrains color themes for [Lumide IDE](https://lumide.dev).

This plugin provides JetBrains editor color schemes and UI palettes for Lumide, including Fleet (Islands), Darcula, and standard JetBrains Dark and Light themes.

## Features

- **Editor & UI Styling**: Editor backgrounds, syntax token colors, line numbers, gutters, selection highlights, and diff views matching JetBrains IDEs.
- **Dark and Light Variants**: Supports both dark and light modes.
- **Static Definitions**: Themes are defined via JSON configurations loaded directly by Lumide.

## Installation

Install via the Lumide Plugin Marketplace, or install manually:
1. Clone this repository.
2. Open Lumide and navigate to **Plugins → Load Local Plugin**.
3. Select this directory.
